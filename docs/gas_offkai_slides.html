Why Codex CLI?

なぜ Codex CLI を選ぶのか

Git Strategy

セーブポイントとして git を使う

💾
Codex実行前（手動）
AIがファイルを書き換える前に、今の状態を保存しておく。何かあっても戻せる。
# セーブポイントを作る
git add .
git commit -m "chore: Codex実行前"
🤖
Codex実行後（自動）
AGENTS.md の指示通り、Codex がコンベンショナルコミット形式で自動記録する。
# Codexが自動でコミット
feat: Gmail一覧化GASを作成
# あとはpushするだけ
git push
06 / 10
Key Concept

AGENTS.md ＝ AIへの指示書

📝
書くこと
・プロジェクトの概要
・作りたい機能の仕様
・コードの書き方のルール
・gitコミットの方針

→ 日本語でOK。箇条書きでOK。
✨
何が嬉しいか
・毎回プロンプトを考えなくていい
・チームで同じ方針を共有できる
・仕様変更はファイルを更新するだけ
・使うほど「自分の仕様書」に育つ

→ 書き方が上手くなるほど作れるものが増える
